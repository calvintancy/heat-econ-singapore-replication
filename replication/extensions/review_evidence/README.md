# Archived review evidence

These are completed review/verification snapshots, copied without rewriting their
original paths, timestamps, model receipts or findings. Absolute/local paths in a
receipt identify the execution that occurred; they are not required installation
paths for the analytical replication. The numerical replication uses the source
verifiers and frozen inputs directly, without calling an external language model.

The design/inference Fable lanes examine the original e47edee release snapshot.
The new-methods lane examines the initial literature-extension snapshot. Final
raw-history/rank corrections, seasonal and full-control companions, and the final
HTML have separate independent numerical/presentation checks. A historical model
review is not mislabelled as a review of subsequent source changes.

Only completed, authenticated provider receipts identifying the exact served
`claude-fable-5-2` model are counted. Generic rolling-alias probes and failed
authentication attempts are excluded from the review count. Review tools used an
isolated-write sandbox so they could create their own probes; source, input and
result mutations were outside their requested scope. The original review reports
and exact provider receipts are retained for inspection.

The receipt-history acceptance records two consecutive all-family verification
runs and eight mutation/failure fixtures. Its source-only execution overlay
preserves the old input/result references. The one-temperature rank proof applies
only to its balanced single-feature equality contrast and must not be extended
to stacked lag/seasonal response vectors.
